# Versi 2026.10.19 — posisi awal kampus

## Pembaruan 2026.10.19.5 — panel HP seperempat layar

URL terbaru: https://upicampusmap.github.io/project-webgis-upi-main/map.html?v=2026.10.19.5

- Panel HP memakai 25dvh pada tampilan awal. Minimum 146px ditambah safe area
  menjaga pencarian dan tiga tab tetap dapat ditekan pada layar pendek.
- Mode ringkas menampilkan pencarian, tab utama dan tombol Perbesar. Daftar
  lengkap muncul setelah menekan Perbesar/tab atau membuka detail; Perkecil
  mengembalikannya ke mode ringkas. Pencarian memperbesar ruang untuk saran.
- Memuat ulang data atau merender filter tidak memperbesar panel ringkas.
  Mencari kembali setelah memperkecil detail beralih ke daftar tanpa menghilangkan input.
- Padding peta dan posisi legenda mengikuti tinggi panel yang sedang terlihat,
  termasuk mode ringkas, diperbesar, detail, serta panel tertutup saat popup dibuka.
- Ketika popup dibuka, panel langsung mengecil tanpa menunggu animasi transform.
  Ini menjaga ruang popup pada perangkat yang sedang sibuk atau frame yang tertunda.
- Reset membekukan perpindahan kamera sebelum memusatkan kampus, sehingga
  animasi pembulatan zoom tidak menimpa tampilan yang baru diatur.
- Validasi: 9/9 tes Node dan 32/32 skenario browser lulus pada viewport
  1280×720, 390×844, dan 320×568. Klik nyata pada pencarian lalu Perkecil,
  serta perubahan dari desktop ke HP dengan input aktif, juga diperiksa.

## Pembaruan 2026.10.19.2 — geser filter kategori

URL terbaru: https://upicampusmap.github.io/project-webgis-upi-main/map.html?v=2026.10.19.2

  ada ruang geser. Di ujung deretan, scroll vertikal kembali diteruskan ke sidebar.

  posisi horizontal kategori dipertahankan ketika filter atau kelompok diklik.

  1280×720, 390×844, dan 320×568. Roda mouse dan drag juga dicoba langsung melalui
  input browser, termasuk verifikasi drag tidak memilih kategori dan klik tetap bekerja.

## Perbaikan

Koordinat awal sebelumnya berada di sisi tenggara kampus dan tidak memperhitungkan
panel informasi. Kini pusat awal diturunkan dari batas kampus. Setelah layout siap,
`fitBounds` menampilkan keseluruhan batas kampus di tengah area yang tidak tertutup
toolbar, sidebar desktop, atau panel bawah HP. Zoom menyesuaikan ukuran layar.

Tombol Kembalikan Tampilan memakai aturan yang sama. Popup ditutup dan animasi lama
dihentikan sebelum reset agar kamera tidak tergeser lagi oleh penyesuaian popup.
Pemusatan awal dilakukan sebelum pemuatan data, sehingga deep link tetap dapat
memusatkan gedung yang dituju setelah datanya siap. Koordinat data tidak diubah.

Seluruh aset dan impor modul menggunakan versi 2026.10.19 untuk menghindari cache
rilis sebelumnya.
