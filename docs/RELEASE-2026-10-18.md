# Versi uji SUS 2026.10.18

Pembaruan 2026.10.18.1: tombol × pada kolom pencarian menghapus teks, saran,
dan pesan pencarian sekali klik, kemudian mempertahankan fokus input. Tombol
muncul hanya saat ada teks, termasuk setelah memilih saran. Aset dinaikkan ke
versi yang sama untuk menghindari cache lama. Pengujian Node 9/9 dan skenario
browser 21/21 lulus pada desktop serta viewport HP 390×844 sebelum publikasi.

Target: https://upicampusmap.github.io/project-webgis-upi-main/map.html

Rilis ini menggabungkan audit/refactoring dan pembaruan UI tanggal 15 Oktober 2026.
Catatan "belum dipublikasikan" pada AUDIT.md dan UI-UX.md adalah status historis
saat kedua pekerjaan tersebut diselesaikan. Status publikasi aktual mengikuti
deployment GitHub Pages untuk commit rilis ini.

## Cakupan

- 77 lokasi kampus, pencarian, filter kategori, detail, dan tautan berbagi.
- 46 area parkir mobil serta 3 area parkir motor dengan render SVG satu path per fitur.
- Panel desktop mengambang, panel bawah HP, popup yang menyesuaikan ruang layar.
- GPS dalam kampus: popup dibuka lebih dahulu, lalu fokus peta dilakukan tanpa
  animasi yang berkompetisi dengan handler popup. Batas area layanan tetap diperiksa.
- Tab Info menjelaskan bahwa informasi gedung mengikuti data yang tersedia.
- CSS, entry script, serta seluruh impor modul menggunakan penanda versi yang
  sama agar cache pengunjung lama tidak mencampurkan kode dua rilis.
  Untuk rilis berikutnya, jalankan `node scripts/version-assets.mjs YYYY.MM.DD`
  dengan versi baru sebelum commit/publikasi.

## Pemeriksaan sebelum rilis

- 9/9 pengujian Node lulus; kapitalisasi dan path aset diperiksa terhadap Git.
- 20/20 skenario browser lulus pada desktop default serta viewport 390×844,
  termasuk simulasi GPS di dalam/luar kampus, pencarian, layer, popup, detail,
  pemuatan ulang dan pemulihan kegagalan parkir.
- Perubahan UI sebelumnya juga diperiksa pada viewport 320×568, 844×390,
  dan 1280×720. Pemeriksaan viewport bukan pengujian HP fisik.

## Batasan data dan pengujian

30 foto belum tersedia dan delapan lokasi baru masih memerlukan pelengkapan metadata.
Fallback inisial tetap digunakan. Validitas format koordinat tidak membuktikan
ketelitian posisi terhadap kondisi lapangan. GPS perangkat nyata dan izin browser
tetap memerlukan pemeriksaan di kampus. Situs memerlukan koneksi internet/CDN.

Gunakan versi yang sama selama satu periode pengambilan data SUS dan catat tanggal
serta commit yang digunakan pada laporan penelitian. Halaman pengujian `tests/`
terpisah dan tidak dimuat pada halaman produk.
